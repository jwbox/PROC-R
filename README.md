A repository of examples of using PROC R

**R_Info.sas** runs code to capture the version, location, and package listing for the R environment. Requires gt package, you may need to delete that section
**ProcR_Overview.sas** demonstrates all of the PROC R specific stuff, from moving datasets to macro variables, SAS functions, and code execution. 
**Scatter.step** is a custom step that makes a ggplot scatterplot from a SAS dataset.
