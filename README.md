A repository of examples of using PROC R
<UL>
<LI><B>R_Info.sas</B> runs code to capture the version, location, and package listing for the R environment. Requires gt package, you may need to delete that section
<LI><B>ProcR_Overview.sas</B> demonstrates all of the PROC R specific stuff, from moving datasets to macro variables, SAS functions, and code execution. 
<LI><B>Scatter.step</B> is a custom step that makes a ggplot scatterplot from a SAS dataset. 
</UL>
